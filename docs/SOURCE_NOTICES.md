# Source notices

The compiler-derived scripts retain the license of their source repository
(see the top-level LICENSE). Benchmark and dependency sources retain their
own upstream licenses and notices. The migration map records the original
repository commit and path for each transferred file; individual source
headers and manifests identify additional upstream origins. Proprietary SDK
components must be supplied separately and are not part of this repository.

Published archives use stable run identifiers in place of calendar stamps.
Internal machine details and lab-only PVA records have been removed. Retained
commit and source hashes identify the original revisions; archived log hashes
may refer to the original bytes before publication cleanup. Regenerate fresh
proofs and measurements with the reproduction drivers instead of treating
sanitized historical logs as fresh validation attestations.
