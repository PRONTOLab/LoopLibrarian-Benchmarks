# Source notices

Compiler-derived scripts retain the license of their source repository; see
[LICENSE](../LICENSE). Benchmark and dependency sources retain their upstream
licenses and notices. Source headers and manifests identify their origins.

`dependency_sources/repos.json` records public dependency revisions. Library
reference manifests in the Polygeist submodule record source hashes and any
adaptations. Proprietary libraries and SDK components must be installed
separately and are not redistributed in this repository.
