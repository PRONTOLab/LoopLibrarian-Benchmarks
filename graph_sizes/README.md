# GEMM e-graph sizes

Measure the GEMM graphs generated by LoopLibrarian and SpEQ.

```
python3 setup.py speq
python3 reproduce.py graph_sizes --output results/runs/graphs
```

Allow 2–10 minutes after [setup](../docs/reproduction.md), excluding SpEQ setup.
`summary.json` records the counts; serialized LoopLibrarian graphs and SpEQ DOT
files are saved beside it. The reported result is 370 SpEQ nodes versus 21
LoopLibrarian nodes.

These counts use different graph scopes. LoopLibrarian counts the largest
accepted scalar proof: 18 function nodes plus three primitive leaves. SpEQ
counts a whole LLVM loop graph, with primitive values stored inline in node
labels. Use these conventions when comparing regenerated graphs.
